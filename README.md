# Orbit

一个本地优先的个人目标管理系统 —— 目标 / 里程碑 / 任务 / 复盘，数据只存在你自己的手机里。

无需注册、无服务器、无云同步。装到 iPhone 主屏幕后像独立 app 一样离线可用。

---

## 怎么安装（iPhone Safari）

1. 用 Safari 打开：
   **`https://leerediary.github.io/orbit`**

2. 点底部 **分享** 按钮（方框 + 向上箭头）

3. 往下滑，选 **添加到主屏幕**

4. 确认名称「Orbit」→ 点右上角 **添加**

5. 回到主屏幕，点「Orbit」图标打开，之后可以离线使用

> 如果没看到「分享」按钮，可以在打开链接后往下滑一点，底部工具栏会出现。

---

## 数据在哪，安全吗

所有数据都存在你手机的浏览器本地存储（IndexedDB）里，不上传到任何服务器。不同设备的数据互相隔离 —— 即使别人也安装同一个链接，看到的是他们自己的数据，和你的完全无关。

---

## 重要：定期备份

装到主屏幕的 PWA **不会**被 Safari 自动清理，但如果手机存储极度紧张，系统仍可能清掉浏览器本地数据（IndexedDB）。

所以请定期使用 app 内的 **导出备份** 功能保存一份备份文件：

- 打开 app → 点右上角 **设置** → **导出备份**
- 下载的 `.json` 文件就是完整数据备份
- 换设备或清缓存后，用 **设置 → 导入备份** 恢复
